## Grouped-Query Attention (GQA): Rank, Expressivity, and Systems Tradeoffs

### From MHA to MQA to GQA

In standard Multi-Head Attention (MHA), each head has independent projections:

$$
Q_h = W_Q^h X, \quad
K_h = W_K^h X, \quad
V_h = W_V^h X
$$

Each head computes:

$$
\text{Attn}_h = \text{softmax}\left(\frac{Q_h K_h^T}{\sqrt{d}}\right)V_h
$$

This maximizes representational diversity but requires storing $H$ separate KV caches during autoregressive decoding.

---

### Multi-Query Attention (MQA)

MQA shares key and value projections across all heads:

$$
Q_h = W_Q^h X
$$

$$
K = W_K X, \quad V = W_V X
$$

Attention becomes:

$$
\text{Attn}_h = \text{softmax}\left(\frac{Q_h K^T}{\sqrt{d}}\right)V
$$

KV cache size reduces by a factor of $H$, significantly lowering memory bandwidth.

However, performance degrades because:

- All heads share the same key-value subspace  
- Independent similarity metrics collapse  
- Effective rank of the attention structure is reduced  

---

### Grouped-Query Attention (GQA)

GQA introduces an intermediate design:

- $H$ query heads  
- $G$ key-value heads, where $1 < G < H$  

Each group of queries shares one KV projection:

$$
Q_h = W_Q^h X
$$

$$
K_g = W_K^g X, \quad V_g = W_V^g X
$$

Attention becomes:

$$
\text{Attn}_h =
\text{softmax}\left(\frac{Q_h K_{g(h)}^T}{\sqrt{d}}\right)V_{g(h)}
$$

KV cache size now scales as:

$$
\text{KV size} \propto G \times L \times d
$$

instead of:

$$
H \times L \times d
$$

This reduces memory bandwidth by a factor of $\frac{H}{G}$ while preserving much of MHA’s expressivity.

---

## Why Query Diversity Matters More Than Key Diversity

Attention scores are:

$$
S_h = Q_h K^T
$$

Interpretation:

- Query = what the current token is searching for  
- Key = how past tokens are indexed in memory  

During decoding:

- Query comes from the current token  
- Keys represent stored context  

Different $Q_h$ projections allow different heads to search for:

- Syntax  
- Entities  
- Long-range dependencies  
- Discourse structure  

Even if keys are shared, different queries produce different attention distributions:

$$
\alpha_h = \text{softmax}(Q_h K^T)
$$

Thus, search diversity is preserved even when memory subspaces are partially shared.

---

## Linear Algebra / Rank Perspective

In MHA:

$$
S_h = Q_h K_h^T
$$

Each head learns an independent similarity metric.  
The attention tensor has high effective rank.

In MQA:

$$
S_h = Q_h K^T
$$

All heads share a single key subspace.  
The overall similarity structure becomes low-rank.

In GQA:

$$
S_h = Q_h K_{g(h)}^T
$$

The number of independent key subspaces is reduced from $H$ to $G$.

Thus:

- MHA → full multi-metric attention  
- GQA → grouped low-rank attention  
- MQA → aggressively low-rank attention  

GQA acts as a structured rank constraint.

---

## Why MQA Degrades More Than GQA

MQA forces:

- One shared $W_K$  
- One shared $W_V$  

This eliminates head-level specialization in memory representation.

GQA restores partial specialization by allowing multiple KV groups.

Empirically:

- Small models tolerate MQA  
- Larger models require $G > 1$ to maintain quality  
- There exists an optimal grouping size depending on model scale  

---

## Systems View: KV Cache and Memory Bandwidth

During autoregressive decoding, the bottleneck is often:

- Reading KV cache from memory  
- Not matrix multiplication  

KV cache per layer:

MHA:
$$
\text{Memory} \propto H \times L \times d
$$

MQA:
$$
\text{Memory} \propto 1 \times L \times d
$$

GQA:
$$
\text{Memory} \propto G \times L \times d
$$

Reducing KV heads reduces:

- GPU memory traffic  
- Cache footprint  
- Decoding latency  

This is why GQA is typically applied only to **decoder self-attention**, not encoder layers.

---

## Conceptual Summary

Grouped-Query Attention assumes:

> Multiple ways of searching memory are more important than multiple ways of storing memory.

By preserving query diversity while reducing the number of independent key-value subspaces, GQA achieves near-MHA quality with significantly improved decoding efficiency.
