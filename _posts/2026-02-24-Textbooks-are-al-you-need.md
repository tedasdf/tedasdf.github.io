# Textbooks Are All You Need: The Phi-1 Strategy

The Phi-1 paper (Microsoft Research) is a foundational study for anyone building **Small Language Models (SLMs)**. It demonstrates that by focusing on "textbook-quality" data, a 1.3B parameter model can outperform models 100x its size.

## 🏗️ The Training Pipeline
The most critical takeaway is the two-stage process used to build the model. It is important to note that for different sizes (1.3B vs. 350M), the researchers trained **entirely separate base models** from scratch using the same data.



### 1. Pre-training: The "Base" Stage
* **Model:** `phi-1-base`
* **Dataset:** **CodeTextbook** (~7B tokens)
    * **Filtered Web Code (6B tokens):** A subset of The Stack/StackOverflow. They used a classifier to keep only "educational" snippets, removing boilerplate and non-self-contained code.
    * **Synthetic Textbooks (1B tokens):** GPT-3.5 generated Python textbooks to provide structured, high-signal diversity.
* **Goal:** To teach the model general reasoning and coding logic.

### 2. Fine-tuning: The "Specialist" Stage
* **Model:** `phi-1` (Final)
* **Dataset:** **CodeExercises** (~180M tokens)
    * Purely synthetic Python exercises and solutions generated by GPT-3.5.
* **Goal:** To "align" the model to solve specific tasks and pass benchmarks like HumanEval.

## 📊 Performance Benchmarks
The results break traditional scaling laws by showing that a tiny model can rival massive ones if the data is "Gold" quality.

| Model | Parameters | HumanEval (Pass@1) |
| :--- | :--- | :--- |
| **phi-1** | **1.3B** | **50.6%** |
| **phi-1-small** | **350M** | **45.0%** |
| GPT-3.5 | 175B+ | 47.0% |
| StarCoder | 15B | 33.6% |

## 🧠 Key Insights for my SLM Project
1.  **Independent Bases:** Even though `phi-1-small` uses the same data, it is a different architecture. I must decide early if I am training a 350M or 1.3B model as they require separate pre-training runs.
2.  **Data Filtering is King:** Raw web data (StackOverflow) is often "noise." Using a "quality classifier" (like their Random Forest model) to prune the dataset is mandatory.
3.  **The Finetuning "Boost":** The jump from `phi-1-base` to `phi-1` proves that a small amount of high-quality exercises (~180M tokens) is what actually unlocks the model's ability to "think" through a problem.
